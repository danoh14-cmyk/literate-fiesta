# FIT TIMER v5.5 글로벌 언어 지원

- 휴대전화 언어가 한국어이면 한국어, 그 외에는 영어로 자동 표시합니다.
- 화면 상단의 Language / 언어 선택에서 자동 / 한국어 / English를 수동 선택할 수 있으며 기기에 저장됩니다.
- 주요 메뉴, 버튼, 운동명, 음성 안내를 영어로 표시하도록 지원합니다. 일부 긴 설명과 동적 문구는 한국어가 남을 수 있으므로 실제 기기에서 검수하세요.
- Android 네이티브 TTS도 한국어/영어로 전환합니다. 사용 가능한 음성은 기기 TTS 엔진에 따라 다릅니다.
- 기존 v5.4 운동 사이 휴식시간, 종료 확인 기능을 유지합니다.
- AdMob 실제 광고 SDK/광고 ID, 결제 및 구독 기능은 아직 연결되지 않았습니다.
- Android API 36 빌드 도구가 필요합니다. GitHub Actions 환경에서 실제 빌드 테스트가 필요합니다.
- Play Store 글로벌 출시 전 전체 문구 번역, 영어 음성, 개인정보처리방침, 사진 라이선스 및 AAB 서명을 검증해야 합니다.
